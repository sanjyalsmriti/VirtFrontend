# Virt - Frontend

React + JavaScript (Vite) implementation of Frontend: Figma UI screens.

## Tech stack

- **Vite** + **React 18**
- **JavaScript** (no TypeScript)
- **React Router** (for Task 1 & Task 2 screens)

## Getting started

1. Install dependencies:

   ```bash
   npm install
   ```

2. Run the development server:

   ```bash
   npm run dev
   ```

3. Open [http://localhost:5173](http://localhost:5173).

## Project structure

- **/** — Home (links to both screens)
- **/task1** — Your SkillShikshya Journey (4 cards)
- **/task2** — Dive Into What's Hot (course cards)

## Build

```bash
npm run build
npm run preview
```

`dist/` is the production output.
